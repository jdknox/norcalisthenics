# How to fix tight hamstrings permanently
2026-07-20

[In this video](https://www.youtube.com/watch?v=W7DVR9TlpOs) Woods addresses the reader directly: "your hamstrings are probably tight and you've probably tried stretching them."

Below is a paraphrased summary, not a transcript.

## Diagnosis
- Frames tightness as a nervous-system safety threshold that limits range of motion, not a fixed physical property of the muscle tissue.
- Hamstrings cross both the hip and knee joints — maximum stretch occurs with the hip flexed and the knee extended at the same time.
- Passive stretching pushes temporarily past the current threshold (giving short-term relief), but the underlying baseline threshold snaps back once the stretch ends — no lasting change results.

## Fix
- Loaded strength training at end range (not stretching) — this teaches the nervous system the position is safe to bear load in, which permanently shifts the threshold outward.
- Once regular strength training already covers full range of motion, this is described as self-maintaining — no separate ongoing mobility work needed.

## Two movements
1. **"Pike"** — feet together, knees locked, weighted hip-hinge down into end range, then actively pull back out using the tensioned/stretched muscles (primarily hamstrings/calves).
2. **"Pancake"** — same pattern with legs spread (shifts emphasis toward adductors/inner thigh); if the starting position is inaccessible, sit on an elevated platform to reduce the hip-flexion angle needed.

## Loading and dosage
- Minimum recommended external load: ~20–25 kg / 45 lb (a weight plate or weighted vest), held/positioned in front of the body to create resistance through the range.
- Baseline dosage: ~10 reps per movement per set (he sometimes does up to ~30 reps on a pancake set when it feels productive — not required).
- Frequency: after strength sessions when already warmed up, 2–4x/week if actively building new range; total time for both movements is roughly 5 minutes.
- Framed as usable in two ways: as an as-needed "mobility first aid" tool (e.g. after long sitting), or, done consistently over a couple of months, as a way to build a genuinely new, more comfortable baseline range.
