# Woods training summaries

Paraphrased (never verbatim) summaries of Jack H. Woods (jackhwoods.com)
videos/posts, organized to answer questions about his training methods
and philosophy without re-reading every source file. See `CLAUDE.md`
for authoring rules (naming, taxonomy, paraphrase limits).

## Categories
- **`training-system/`** — the six-movement bodyweight strength method:
  what to train, how to scale it, injury management. Start here for
  "how does Woods train/program X" questions.
- **`flexibility/`** — mobility work not tied to one movement (his
  nervous-system-limit theory and end-range loading method).
- **`diet/`** — nutrition: protein targets, deficit/surplus cycling,
  his one-meal "barbell" eating structure.
- **`philosophy/`** — non-fitness mindset/goal-setting; the same
  minimalist framework applied to life, work, and learning.
- **`travel/`** — training/eating while traveling.

Each category has its own `README.md` with a theme summary and a
per-file index — check the relevant one(s) before opening individual
summary files. `training-system/` has a further split by movement.
