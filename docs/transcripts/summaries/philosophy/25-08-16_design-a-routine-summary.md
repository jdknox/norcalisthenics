# How to design a routine to actually achieve your goal
2025-08-16

[In this video](https://www.youtube.com/watch?v=tle3EYwTybI) Woods frames the stakes: "Every goal that you have or haven't achieved is a result" of what gets done each week.

Below is a paraphrased summary, not a transcript. This is a general goal-setting/routine-design framework, applied across fitness, language, reading, and mindfulness examples.

## Three-step process
### Step 1 — Decide what you're NOT going to pursue
- Frames routine design as fundamentally a subtraction exercise: given limited time/energy/focus, the number of goals actively pursued has to be small for any of them to get done well.
- Instructs choosing the minimum set of goals worth focusing on for roughly the next year, before building any routine around them — explicitly states his own biggest breakthroughs came from removing goals/activities, not adding them (citing narrowing his own fitness system down to 6 movements as the clearest example).

### Step 2 — Set the smallest possible input target for each goal, not the most ambitious one
- Identifies a common mistake: designing a routine around peak motivation/energy (i.e., an ambitious daily/weekly time commitment) rather than around a minimum viable, easily repeatable input.
- Reasoning: results are attributed almost entirely to the number of times a person shows up and does *something* effective, not the size of any individual session — so a routine's job is just to guarantee consistent minimal opportunities to do that.
- Worked example set across five example goals: handstands/muscle-ups/visible-abs/general-strength (train the 6 basic movement patterns, once/week each, effort-based rather than time-based); conversational Spanish (5 minutes of practice each weekday); reading a target book list (5 minutes of reading each weekday); being more present (a daily meditation session, no time target — just showing up); plus 1–2 chosen flexibility movements added once or twice weekly if relevant.
- Notes the daily-weekday-only targets deliberately leave weekends free as a buffer for missed days.

### Step 3 — Make each input non-negotiable by scheduling it explicitly
- Recommends placing every chosen input as a recurring calendar event at the time it's most likely to get done, rather than relying on memory or willpower/habit alone — reasoning that daily life is inherently disruptive, so the routine needs to be resilient (reschedulable) rather than rigid.
- Explicit rule: if a scheduled session is missed, it gets moved (to a specific new time, using the weekend buffer if needed for weekday-based goals) rather than skipped outright — the target is to complete the input for the week, not necessarily on the originally planned day.
- Frames consistency (not training technique, timing, or optimization) as the single largest determinant of whether a goal is actually reached, and treats willpower-dependent routines as inherently unreliable compared to a pre-scheduled, minimum-viable one.
