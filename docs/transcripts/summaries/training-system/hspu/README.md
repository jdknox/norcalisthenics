# training-system/hspu/ — handstand pushup (vertical push)

Theme: builds vertical-push strength via a self-scaled negative-then-
positive rep, using hand-loading position (feet-on-floor → elevated →
straps → freestanding) as the sole difficulty knob, once/week.
Handstand balance is treated as a near-free byproduct of that
strength, not something to drill separately.

## Files
- `25-05-05_shoulders-at-home-summary.md` — Full HSPU progression: scale via hand-loading %, find sticking point each rep, once/week.
- `25-12-12_handstand-practice-summary.md` — Dedicated balance practice is counterproductive; build vertical-push strength first.
- `26-06-15_calisthenics-progress-summary.md` — Track your "frontier" (current max difficulty), not rep counts, across the progression.
