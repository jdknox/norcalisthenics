# training-system/ppu/ — planche pushup (horizontal push)

Theme: scales pushup/planche difficulty purely via shoulder-to-hand
horizontal lean distance, self-adjusted rep-by-rep to stay at maximal
effort, once/week. True planche strength is flagged as a separate,
non-generalizing add-on outside the core six-movement system — though
correcting scapula protraction/lockout form within the normal pushup
itself is presented as a free, no-extra-time way to reclaim some of
that skill-specific strength without a dedicated add-on session.

## Files
- `25-10-09_pushup-strength-summary.md` — Forward-lean distance is the pushup difficulty knob; self-scale each rep to genuine failure.
- `26-09-07_planche-cost-summary.md` — Planche/front lever need separate "software" coordination training, doubling session time.
- `26-09-21_calisthenics-mistakes-summary.md` — Fix scapula protraction on planche pushups and top-range wrist-to-body on front lever rows to unlock skill-specific free gains.
