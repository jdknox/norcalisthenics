# training-system/nordic-curl/ — Nordic curl (knee flexion)

Theme: scales via hip-hinge angle and hand support (not external
load) to train full 90°-180° knee flexion to hips-on-floor depth,
once/week — the knee-flexion counterpart to the squat.

- `24-10-08_nordic-curl-2min-summary.md` — Hip hinge and hand support are the two scaling variables; rep must reach hips-on-floor to count.
