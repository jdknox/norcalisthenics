# You only need these 6 movements
2026-02-06

[In this video](https://www.youtube.com/watch?v=F6OKdue0UBw) Woods states his track record: "I've trained the same six exercises for the past six years" for under 40 minutes a week.

Below is a paraphrased summary, not a transcript. This is his fullest single-video breakdown of each of the six movements individually (complementing the fuller routine described in "The exact routine I used to transform my body," summarized separately).

## Core argument
- More exercises/variety dilutes effort and slows recovery without adding benefit — a muscle responds to being made stronger at its function, not to variety of stimulus. Fewer movements, trained harder and more consistently, is framed as more effective than a broader routine.

## The six movements, each with: prime mover(s), how it's loaded/progressed, and the 3-stage path (ground zero → checkpoint → end goal)
1. **Horizontal push** (pec major) — build via forward lean on rings until feet leave the ground, then extend further into a planche. Ground zero: guided pushup, no forward lean. Checkpoint: tuck planche (feet off ground). End goal: straddle or full bent-arm planche.
2. **Horizontal pull** (traps, rhomboids, rear delts, lats) — build via pushing rings away (toward feet) during a bodyweight row until feet leave the ground, extending toward a front lever. Ground zero: bodyweight row, no added distance/load. Checkpoint: tuck front lever row (feet off ground). End goal: full front lever.
3. **Vertical push** (front/side deltoids, triceps) — build via progressively loading more bodyweight onto the hands in an inverted position. Ground zero: pike pushup, most weight on feet. Checkpoint: full bodyweight loaded on hands at the bottom position. End goal: unassisted freestanding handstand pushup.
4. **Vertical pull** (lats, biceps) — build via progressively loading more bodyweight onto one arm during an assisted chin-up. Ground zero: fully assisted (all weight on feet). Checkpoint: full-range two-arm chin-up. End goal: full-range, unassisted one-arm chin-up.
5. **Squat / knee extension** (glutes, quads) — build via a loaded single-leg squat, using hands/other foot for assistance as needed. Ground zero: fully assisted, no load on the working leg. Checkpoint: unassisted full-range bodyweight single-leg squat. End goal: single-leg squat loaded to 75% bodyweight (his example: 80 kg bodyweight → 60 kg external load).
6. **Knee flexion** (hamstrings) — build via a Nordic curl, using as little hand-assistance as possible. Ground zero: heavily assisted, going through the pattern. Checkpoint: partial range without hands. End goal: strict, no-hands Nordic curl with a straight body.

## On what's "missing"
- Acknowledges core, lower back, forearms, and calves aren't directly targeted but states they get substantial indirect work as stabilizers across these six movements (particularly in front levers, one-arm chin-ups, single-leg squats, handstand pushups, and loaded single-leg squats) — framed as sufficient without dedicated isolation work, since weak stabilizers will limit and therefore get pulled along by progress in the main lifts.
- Explicitly excludes hip flexion and ankle dorsiflexion training as optional/not required for these results — relevant mainly for specific performance/injury-prevention goals, not general physique/strength outcomes.

## Two execution principles emphasized
1. **Progressive overload** — the only thing that actually matters; volume/routine design "on paper" is irrelevant if strength isn't increasing.
2. **Full range of motion at max intensity** — training the entire accessible range, and self-scaling difficulty (rather than using a fixed external load that only challenges one point in the range) so that even a single set can be taken to genuine failure throughout the full range — described as the mechanism that makes 1 set/movement/week sufficient.
