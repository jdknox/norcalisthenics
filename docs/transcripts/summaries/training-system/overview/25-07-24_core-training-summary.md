# All you need to build six-pack abs | Core Training 101
2025-07-24

[In this video](https://www.youtube.com/watch?v=gkfS_AsNWzs) Woods states plainly: "I do not train any core exercises, and if your goals" are a six-pack or better movement ability, he argues you don't need to either.

Below is a paraphrased summary, not a transcript.

## Core argument — aesthetics
- Visible abs are attributed entirely to body composition (low enough body fat that the existing ab muscles become visible through the skin), not core muscle strength or size — the muscles are already present; a layer of fat over them is what prevents visible separation/definition, regardless of how developed the underlying muscle is.
- Explicitly rejects "spot reduction" (the idea that ab-specific exercise like sit-ups preferentially removes fat from that area) as not reflecting how fat loss works physiologically.
- Frames the actual path to visible abs as: build overall muscle mass first (so there's more definition to reveal once lean), then reduce body fat via a calorie deficit — with no ab-specific training required at either stage.

## Core argument — function/strength
- Argues the core functions as a stabilizer for the major "prime mover" muscle groups (shoulders, hips, elbows, knees), not as the primary driver of strength or movement capacity — so core strength is rarely the actual limiting factor for advanced bodyweight skills or general functional movement.
- States that if the core genuinely were a limiting factor for a specific movement, it would develop automatically as a byproduct of training that movement pattern toward a genuine strength goal (using the front lever — a back/pulling exercise — as the example of a movement commonly assumed to require exceptional dedicated core strength, but which is instead primarily built through horizontal-pulling strength).
- Concludes that time spent on isolated core exercises is time diverted from training the six basic movement patterns that actually drive both the strength/mobility and the muscle-mass outcomes being sought.

## Combined protocol (his stated "all you need")
1. Build strength across the six basic movement patterns referenced throughout his content (see the separately summarized "six movements" video) — this builds the muscle mass, including core musculature as needed to support the prime movers.
2. Reduce body fat via a calorie deficit, run in cycles of roughly 4–12 weeks depending on how much fat needs to be lost, repeated as needed until abs are visible at the desired level of definition.
- No dedicated ab/core exercises (crunches, leg raises, etc.) are included in this protocol.
