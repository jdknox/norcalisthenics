# training-system/overview/

Theme: six movement patterns — horizontal push (planche pushup),
horizontal pull (front lever row), vertical push (handstand pushup),
vertical pull (one-arm chin-up), knee extension (single-leg squat),
knee flexion (Nordic curl) — each trained to one continuous, self-
scaled max-effort set weekly (twice for upper body via antagonist
pairing). "Scale to zero": bodyweight leverage makes difficulty
continuously adjustable, so every rep trains true failure across the
full ROM, unlike fixed loads which only challenge one sticking point.
"Forcing the negative" is his signature intensity technique; "no
longer fun" is the stopping rule. Physique = muscle mass (this
training) + body fat (1.8 g/kg protein, periodic deficit cuts — see
`../../diet/`); cardio (8-10k steps) is for wellbeing only, not
physique. Minimal equipment (rings, Nordic strap, weight vests) over
gyms/isolation work — core, mobility, and skills are framed as
automatic byproducts. Stable for 5+ years, with iterative
frequency/volume refinements in later files.
