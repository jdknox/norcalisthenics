# The exact routine I used to transform my body (strength, flexibility, diet)
2026-08-03

[In this video](https://www.youtube.com/watch?v=kfm1i8IyNaA) Woods opens with the premise: "40 minutes a week. What if I told you that was all you needed?"

Below is a paraphrased summary, not a transcript — this is his fullest single-video description of the whole system.

## Strength — six movement patterns
Each pattern has a stated "north star" end-goal skill (a target to progress toward, not something that needs to be reached):
- Horizontal push → planche pushup
- Horizontal pull → front lever row
- Vertical push → handstand pushup
- Vertical pull → one-arm chin-up
- Squat / knee extension → single-leg squat loaded to 75% bodyweight
- Knee flexion → Nordic curl

**Programming:** 1 set per movement, once per week; split across 3 sessions/week (e.g. Mon/Wed/Fri), pairing two opposing-pattern movements per session (horizontal push+pull one day, vertical push+pull another, knee flexion+extension the third). Each session ~10–15 minutes including rig setup and rest; totals ~40 minutes/week. Progressive overload — a slightly harder variation than the previous week for each movement — is the core driver of progress.

## Mobility
- Treated as a byproduct of training the 6 movements through full range of motion, not a separate practice.
- Dedicated end-range loaded stretching is added only for specific flexibility goals (e.g. pike/pancake range for handstand presses), using moderate load (his examples: ~20 kg / 45 lb, or bodyweight), done after strength training, and dropped again once the target range is reached — strength training then maintains it.

## Nutrition — three stated goals: training performance/recovery, general health, and lean sustainable body composition
- **Protein target:** 1.8 g per kg of goal bodyweight/day — often hit largely in one meal (~100+ g protein in that single meal).
- **General intake:** built from whole foods (meat, seafood, eggs, dairy, fruit, vegetables).
- **Carbs:** emphasized especially pre-training, for performance, mood, and sleep; sourced flexibly (fruit, honey, starches) — source doesn't matter much.
- **Fat-loss phase** (for those starting with excess body fat): ~500 kcal/day deficit targeting ~1 lb/week loss, continued until reaching a sustainable lean level, then return to maintenance intake.

## Cardio / steps
- Baseline: 8,000–10,000 steps/day, framed purely for general mental/physical wellbeing — not for fat loss or the strength/mobility/body-composition goals above.
- Higher-intensity cardio (VO2 max work etc.) treated as optional and preference-driven (his own choices: surfing, tennis, basketball).

## Recovery
- Prioritizes sleep and stress management.
- Explicit warning against assuming more training time/frequency linearly increases results — progress is gated by recovery capacity, not just training stimulus.
