# How to build a world-class upper body with a set of gymnastics rings
2025-03-25

[In this video](https://www.youtube.com/watch?v=Hp9LPeT4zTo) Woods opens with the pitch: "Imagine if you could build all the same upper body muscle and strength" that normally takes hours a week, using just a set of rings.

Below is a paraphrased summary, not a transcript. This is a focused, upper-body-only walkthrough of his four-movement system (horizontal/vertical push and pull), presented as a standalone 25-minutes/week routine.

## Core principle — train the movement pattern, not individual muscles or skills
- Uses an analogy: someone able to overhead-press their own bodyweight with a barbell would have little trouble with lighter variations (dumbbell press, machine press) — the underlying strength transfers broadly, so there's no need for a long list of different exercises per muscle group.
- Extends this to skills: states that specifically practicing calisthenics skills (handstands, levers) without the underlying strength was unproductive in his own experience, whereas building raw strength in the corresponding movement pattern (e.g. vertical push strength toward a handstand pushup) produced those skills as a byproduct with minimal dedicated practice.
- Also states that "weak link" muscles (e.g. core, grip) don't need isolated training — pushing progression on the main movement pattern is described as pulling any lagging supporting muscle along with it automatically, since it becomes the limiting factor and therefore gets stimulated as needed.

## Four target movement patterns (goals only; mechanics for each covered in his movement-specific videos)
- Horizontal push (planche pushup), horizontal pull (front lever row), vertical push (handstand pushup), vertical pull (one-arm chin-up) — described as covering all upper-body strength, muscle mass, mobility, and calisthenics-skill needs between them.

## Scaling difficulty
- Difficulty comes from body positioning, not fixed external weight — described generically here as finding the point where a movement is just barely possible ("tipping the threshold"), training there, and continuously re-adjusting (adding assistance/reducing lean, etc.) as different points in the range of motion require different amounts of difficulty to stay maximally challenging.
- Flags full range of motion as commonly neglected: because assistance can always be added to make a rep effortless, it's possible to "cheat" range of motion without noticing — explicitly calls this out as the most common mistake among his students starting this method, and stresses defining and training genuine full range of motion for each movement.

## Programming
- One set per movement, once per week; total time estimate given as roughly 25 minutes/week for the four upper-body movements alone.
- Stopping rule: the same "no longer fun, you're done" cue used throughout his content.
- States the single most important factor for guaranteeing results is simply testing for a bit more strength/difficulty than the previous week, every session — describes this as more important than any technical or programming detail, and the clearest differentiator between students who progress quickly and those who train far more but see little result.
- Split guidance: can be done as one combined session (all four movements, ~25 minutes) or split into two sessions (antagonist pairs — horizontal push+pull one day, vertical push+pull another) across the week if schedule allows, with the latter offering more recovery/potential intensity per movement at the cost of more separate sessions; both are stated to work.
