# training-system/

Woods' core method: six movement patterns, each trained as one
continuous, self-scaled, max-effort set per week (difficulty adjusted
via leverage/lever-distance, not added weight) — "scale to zero" lets
every rep hit true failure across the full range of motion. Total time
~12-40 min/week.

## Subfolders
- **`overview/`** (33 files) — general method, principles, full
  routines, frequency/volume, equipment, beginner starting points.
  Read first for system-level questions.
- **`injury-safety/`** (3 files) — injury causes (volume vs.
  intensity) and his recovery/case-study fixes.
- **`hspu/`** — handstand pushup (vertical push)
- **`ppu/`** — planche pushup (horizontal push)
- **`fl/`** — front lever / row (horizontal pull)
- **`oac/`** — one-arm chin-up (vertical pull)
- **`squat/`** — single-leg squat (knee extension)
- **`nordic-curl/`** — Nordic curl (knee flexion)

For "how do I progress movement X" questions, go straight to that
movement's subfolder rather than `overview/`.
