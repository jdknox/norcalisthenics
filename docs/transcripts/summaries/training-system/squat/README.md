# training-system/squat/ — single-leg squat (knee extension)

Theme: weighted, hand-assisted single-leg (pistol) squat to full
depth covers both knee- and hip-extension strength in one movement;
ankle mobility resolves automatically from training the deepest
accessible range rather than stretching.

## Files
- `25-05-29_legs-one-rep-summary.md` — One weighted single-leg squat rep/week replaces separate squat and deadlift training.
- `26-01-23_deep-squat-mobility-summary.md` — Squat faults are strength-setup errors, not flexibility issues; heel-elevate to fix centering.
- `26-08-31_squat-summary.md` — Squat is the highest-impact single exercise; full-depth pistol variations ranked by specificity.
