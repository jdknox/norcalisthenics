# Woods transcript summaries

Paraphrased (never verbatim) summaries of Jack H. Woods videos/posts
(jackhwoods.com) — one `.md` file per source, for personal reference.

## File naming
`YY-MM-DD_slug-summary.md` — date is the post's publish date, not when
the summary was made. Header inside each file: title, date, video link,
one short attributed quote (<15 words), then paraphrased content.

## Folder taxonomy
- `training-system/overview/` — general method, principles, full-routine
  videos, frequency/volume, equipment, beginner routines
- `training-system/injury-safety/` — injury prevention/recovery
- `training-system/hspu/` — handstand pushup (vertical push)
- `training-system/ppu/` — planche pushup (horizontal push)
- `training-system/fl/` — front lever / row (horizontal pull)
- `training-system/oac/` — one-arm chin-up (vertical pull)
- `training-system/squat/` — single-leg squat (knee extension)
- `training-system/nordic-curl/` — Nordic curl (knee flexion)
- `flexibility/` — mobility work (not tied to one movement above)
- `diet/` — nutrition, protein targets, cutting/bulking
- `travel/` — training/eating while traveling
- `philosophy/` — motivation, goal-setting, life lessons (non-fitness)

New summaries: file under whichever folder above best matches the
content; if it's mainly about one of the six movements, it goes in
that movement's subfolder even if pulled from a general-overview post.

## Rules
- Never reproduce source text verbatim — paraphrase, one short quote
  max per file, per standard copyright limits.
- Don't re-summarize a source already covered; check existing files
  in the target folder first.
- After adding a new summary, add its one-line hook to that folder's
  `README.md` file list, and update the folder's `## Theme` paragraph
  only if the new file introduces an idea not already covered.
