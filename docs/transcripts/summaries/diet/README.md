# diet/

Theme: two numeric anchors — protein 1.8 g/kg goal bodyweight/day
(~140g for him, often one ~500g-meat meal) and a moderate ~500
kcal/day deficit (~0.5kg/week) run in blocks ≤12 weeks/year, with
9+ months/year in a slight surplus. Mechanistic claim: muscle mass
sets a "healthy weight range" below which appetite/hormones force
rebound, so leanness comes from building muscle, not dieting harder,
and is maintained via protein-driven appetite regulation rather than
calorie tracking. Recurring "barbell"/one-meal structure: one
deliberate protein-dense whole-food meal, unrestricted eating
otherwise — "clean eating" and constant tracking framed as
unnecessary.
