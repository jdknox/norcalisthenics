# Ring Workout Program

*Arvanitakis-inspired, adapted for ring training*

**Goal:** Build clean ring pull-ups, stronger ring rows and push-ups, and progress from pike push-ups toward true vertical pushing while keeping the program balanced.

---

## Weekly structure

Train 3 days/week, alternating Workout α and Workout ω.

- Week 1: α / ω / α
- Week 2: ω / α / ω
- Leave at least one rest day after two consecutive strength days.

## Warm-up

- General movement: 3–5 min
- Scapular pull-ups: 1–2 sets x 5–8 slow reps — technique/prep, not a hard strength exercise
- Do not take the warm-up close to failure; main pulling work should still feel fresh

---

## Workout α — Pull-up emphasis

| Exercise | Sets | Target | Purpose |
|---|---|---|---|
| Leg-assisted ring pull-ups | 3 ladders | ladder to top rung | Main vertical pull / pull-up progression |
| Ring push-ups | 3 ladders | ladder to top rung | Main horizontal push |
| Ring rows | 2 | 6–12 reps | Horizontal pull / upper-back |
| Pike push-ups | 2 | 4–12 reps | Shoulder-focused incline push |
| Bulgarian split squat | 3 | 8–15 reps | Knee-dominant lower body |
| Hollow-body hold or plank | 2 | 15–60 sec | Core |

## Workout ω — Row and shoulder emphasis

| Exercise | Sets | Target | Purpose |
|---|---|---|---|
| Ring rows | 3 ladders | ladder to top rung | Main horizontal pull |
| Pike push-ups | 3 ladders | ladder to top rung | Main shoulder / vertical-push progression |
| Leg-assisted ring pull-ups | 2 ladders† | ladder to top rung | Vertical-pull practice |
| Ring push-ups | 2 | 6–12 reps | Horizontal push |
| Reverse lunge or split squat | 3 | 6–12 / leg | Single-leg lower body |
| Hollow-body hold or plank | 2 | 15–60 sec | Core |

† Kept as a ladder despite being secondary here — low max reps favors the ladder ramp regardless of primary/secondary status (see "How to progress").

## Pull-up progression

1. **Leg-assisted ring pull-ups** — straight legs, repeatable setup. Keep ring height and heel position measurable.
2. **Reduce assistance** — make the geometry harder gradually. Don't compensate by pushing harder through the legs.
3. **Mixed reps** — when possible, start a set with one clean unassisted rep, then finish target volume assisted.
4. **Full ring pull-ups** — clean unassisted reps, full hang, controlled start from the scapulae, no kipping, controlled descent.

## Pike push-up progression

1. **Floor pike push-up** — hands and feet on floor, hips high, torso angled toward vertical.
2. **Build to ~12 clean reps** before making the geometry harder.
3. **Elevate the feet** — stable knee-height surface. Rings under the feet = later, less stable option.
4. **Increase range and verticality** — progress gradually toward handstand push-up work.

## How to progress

- Keep 1–3 clean reps in reserve on most sets. Avoid grinding.
- When all sets hit the top of the rep range with clean form, make the exercise slightly harder.
- Ring push-ups/rows: change body angle in small, repeatable increments.
- Assisted pull-ups: reduce assistance rather than adding sloppy reps.
- Pike push-ups: increase clean reps first, then elevate feet or increase ROM.
- Persistent joint/connective-tissue irritation → reduce volume or difficulty before adding more work.
- **Ladder vs. straight:** main horizontal/vertical work (the 3-set movements) runs as ladders — the ramp warms up the joint/tendon and grooves the movement at increasing difficulty. Secondary work runs as straight sets. Exception: leg-assisted pull-ups stay a ladder even when secondary, since low max reps favors the rest-pause ramp regardless of set count.

## Why these exercises are included

| Movement category | Exercise | Role |
|---|---|---|
| Vertical pull | Leg-assisted → full ring pull-up | Lats, elbow flexors, vertical pulling skill |
| Horizontal pull | Ring row | Mid-back, rhomboids, rear delts, scapular retraction |
| Horizontal push | Ring push-up | Chest, triceps, anterior shoulder |
| Incline / vertical-push progression | Pike push-up | Shoulders and triceps; bridge toward handstand push-ups |
| Scapular preparation | Scapular pull-up | Scapular depression and pull-up initiation |
| Lower body | Squat / split squat / reverse lunge | Keeps the program full-body |
| Core | Hollow hold / plank | Trunk control and body tension |

## Arvanitakis basis and adaptations

**From Arvanitakis:** separate horizontal/vertical pulling patterns, pike push-ups as the progression toward handstand push-ups, easier variations when full reps aren't available yet, lower-body and core work included.

**Adapted here:** ring push-ups replace ordinary push-ups, ring rows replace fixed-bar inverted rows, leg-assisted ring pull-ups provide the beginner pull-up progression, scapular pull-ups used as a low-fatigue warm-up (they reinforce the first portion of the pull-up).

## Optional later additions

- **Ring dips** — add only once ring support and pushing strength are comfortable.
- **Handstand push-up progression** — only after elevated pike push-ups are strong and controlled.
- **More demanding lower-body/conditioning work** — add after the basic routine is established, not all at once.
